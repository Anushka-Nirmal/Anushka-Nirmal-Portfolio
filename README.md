# Anushka Nirmal — Portfolio Website

A personal portfolio website for **Anushka Nirmal**, a B.Tech Information Technology student at **VIT Pune** and an aspiring software developer interested in C++, Data Structures & Algorithms, web development, and AI.

The portfolio brings together an introduction, project showcase, skills, education, and contact information in a colorful, interactive design.

## ✨ Features

- **Animated hero section** introducing Anushka and her interests.
- **About section** sharing her learning journey and goals.
- **Interactive project cards** that can be flipped to reveal project details and GitHub links.
- **Projects showcase** covering healthcare, agriculture, campus services, internship matching, and road safety.
- **Skills and technology highlights** for C++, DSA, AI, web development, Git, and learning.
- **Education section** featuring B.Tech in Information Technology at VIT Pune.
- **Contact section** with email, LinkedIn, GitHub, and a contact form that opens the visitor’s email application.
- **Responsive layout** for desktop, tablet, and mobile screens.
- **Motion and visual effects**, including scroll reveals, animated backgrounds, cursor interactions, and a 3D-style cube.
- **Accessibility considerations**, including keyboard focus styles and reduced-motion support.

## 🛠️ Technologies & Design

The portfolio is delivered as a **single HTML file** with its styling and bundled JavaScript included in the file.

- **HTML5** — page structure and content
- **CSS3** — responsive styling, animations, gradients, transitions, and visual effects
- **JavaScript** — interactions, scrolling effects, and dynamic UI behavior
- **React** — used by the bundled frontend application
- **Google Fonts**
  - Bricolage Grotesque
  - Instrument Sans

## ▶️ Run Locally

### Option 1: Open directly

1. Download or clone this repository.
2. Locate `Anushka Nirmal Portfolio.html`.
3. Open the file in a modern browser such as Chrome, Edge, or Firefox.

### Option 2: Use VS Code

1. Open the folder in Visual Studio Code.
2. Open `Anushka Nirmal Portfolio.html`.
3. Use the **Live Server** extension if you prefer to preview it through a local development server.

> The portfolio loads Google Fonts from the internet, so an internet connection may be needed for the intended typography. The rest of the page is packaged in the HTML file.
